API Documentation for Chatbot Integration

Overview

This API allows users to submit queries related to medical advice. The system provides responses based on user inputs, aiming to suggest possible treatments or recommendations.

Endpoint

URL:

HTTP Method

POST

Headers

Content-Type: application/json

Request Body

The request body should be in JSON format and contain the following fields:

| Parameter    | Type   | Required | Description                                                          |
|--------------|--------|----------|----------------------------------------------------------------------|
| user_query   | String | Yes      | The user's question or statement. Example: "I have a cold since 3 weeks what medicine should I take." |
| agent_ans    | String | No       | An optional field for agent responses (if available). Leave empty if the query is initial. |

Example Request Body:

{
    "user_query": "I have a cold since 3 weeks what medicine should I take",
    "agent_ans": ""
}

Response

The response will contain the following information in JSON format:

| Field      | Type   | Description                                               |
|------------|--------|-----------------------------------------------------------|
| answer     | String | The chatbot's response based on the user's query.        |
| status     | String | Indicates whether the request was successful or failed.   |

Example Response:

{
    "answer": "You should consult a doctor for a proper diagnosis.",
    "status": "success"
}
